# 🌐 Projet de groupe PPE1 – Analyse linguistique multilingue

## 🎯 Objectif

Ce projet a pour objectif de **repérer et d'analyser les nuances linguistiques d'un mot** dans **deux langues différentes**, en utilisant des outils du traitement automatique des langues (TAL).

Le mot analysé dans ce projet est : **"course"**  
Les langues étudiées sont :
- 🇫🇷 **Français**
- 🇨🇳 **Chinois mandarin**

---

## 🔍 Méthodologie

### 1. 🌐 Collecte de données textuelles  
- Récupération de contenus en ligne
- Nettoyage des données
- Segmentation lexicale 

### 2. ☁️ Génération de nuages de mots  
- Élimination des mots vides
- Visualisation des cooccurrences

### 3. 📊 Analyse textométrique (via iTrameur)  
- Étude des différentes graphies du mot 
- Analyse des cooccurrences selon la casse

### 4. 🧠 Interprétation linguistique et culturelle  
- Mise en lien entre usages lexicaux et pratiques sociales
- Comparaison interculturelle entre le français et le chinois
